🎬 CineAura – Movie Discovery Website

CineAura is a modern movie discovery web app built with React + TypeScript + Vite.
It allows users to search, explore, and browse movies with a sleek UI and smooth animations.

✨ Features

🔍 Search movies by title

🎭 Browse movies by genre (Action, Adventure, Thriller, etc.)

🎨 Dark gradient theme with black–orange design.

⏳ Custom preloader with animation

🖼️ Responsive design for mobile & desktop

🚀 Hosted on Firebase

🛠️ Tech Stack

React + TypeScript (Frontend)

TailwindCSS (Styling)

Firebase (Hosting & Deployment)

📌 Future Improvements

Add login & user accounts

Save favorite movies

Show trailers & ratings.
